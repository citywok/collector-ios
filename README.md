# research

A dedicated chat project for general internet research.

Every thread created here runs against this repo's `mainline` branch, so
`AGENTS.md` (project instructions) is auto-injected into every session. Those
instructions make every user message a generic question that gets researched
via `web_search` before it is answered, with sources attached.

- `AGENTS.md` — binding standing instructions read by every session.
- Answers here should always carry a `Sources:` list.
